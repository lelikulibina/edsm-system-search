# EDSM System Search

Отдельный HTTP-сервис поиска звёздных систем Elite Dangerous по локальному каталогу EDSM.

## Статус

Проект находится на этапе MVP. Архитектура первой версии зафиксирована в [дизайн-документе](docs/design.md), план работ — в [плане реализации](docs/implementation-plan.md).

## Архитектура

- Rust + Axum для HTTP API.
- SQLite для основного каталога.
- SQLite R*Tree для трёхмерного предварительного пространственного поиска.
- B-tree индекс SQLite для поиска по нормализованным именам.
- Потоковый импорт JSON-массивов EDSM из gzip-дампов.
- Никаких runtime-запросов к EDSM API.

## Важно

Каталог отражает данные EDSM и не является полным каталогом всех систем Elite Dangerous. Отсутствие системы в дампе не означает, что такой системы не существует в игре.

Полная первоначальная загрузка большого дампа может занять значительное время и зависит от диска и процессора сервера. Ограничение «пара часов» относится к разработке MVP, а не гарантированному времени первичного импорта.
